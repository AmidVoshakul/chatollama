## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Node.js + npm
- Ollama (установите с [официального сайта](https://ollama.com))

### Установка и запуск

```bash
cd ollama-web-chat/
chmod +x startvenv.sh
./startvenv.sh
```
